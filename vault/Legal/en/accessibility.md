# Accessibility statement

This website is meant to conform to the Web Content Accessibility Guidelines 2.2, level AA.

> [!spec] Testing
> - Automated — Chromium layout checks at six widths in both colour schemes; axe on sampled template routes at 390 and 1,280 px
> - Manual screen-reader, cross-browser and real-device coverage remains incomplete; see the known limitations below

## Keyboard

Tab moves through links and controls; the first stop is “Skip to content”. Focus is indicated by a 2 px ink outline. On the tools, the sliders move with the arrow keys, and each value can also be typed into its field.

> [!spec] Shortcuts
> - 0 — Home
> - 1 to 4 — Work, Writing, Tools, About, as numbered in the header
> - j / k — Next / previous section of the page
> - n / p — Next / previous project; older / newer essay
> - u — Up one level
> - l — German version where available; otherwise the German home
> - t — Light or dark theme
> - ? — The list of shortcuts; Esc closes it

The shortcuts are single keys and need JavaScript. They are inactive while typing in a field or holding Cmd, Ctrl or Alt. “Keyboard shortcuts” in the footer opens the same list.

## Limitations

The email address is visually generated rather than exposed in HTML. Without JavaScript, a screen-reader user cannot retrieve it through the contact control. The desktop header’s keyboard focus order differs from its visual order. Automated checks do not establish full WCAG conformance; manual screen-reader, browser, device and zoom checks remain incomplete.

Known limitation: the interactive tools need JavaScript. Without JavaScript, the default scenario is shown as text and a table.
