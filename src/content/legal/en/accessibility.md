This website is meant to conform to the Web Content Accessibility Guidelines 2.2, level AA. The statement is voluntary: the Austrian Accessibility Act (Barrierefreiheitsgesetz) does not cover this private site.

> [!spec] Testing
> - Automated — axe, both colour schemes, 320 to 1,280 px, on every change
> - Manual — keyboard operation of every tool; zoom to 200%
> - Planned — one pass with a screen reader (NVDA) before publication

Known limitation: the interactive tools need JavaScript. Without JavaScript, the default scenario is shown as text and a table.

Barriers can be reported to [rafaelbragakribitz@gmail.com](mailto:rafaelbragakribitz@gmail.com). Prepared on 20 Oct 2026.
