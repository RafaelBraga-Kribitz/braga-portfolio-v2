## Hosting and server logs

The website is served through GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA). When a page is accessed, GitHub processes technically necessary data in server logs: IP address, time, the address requested and the browser identifier. The legal basis is the legitimate interest in secure operation (Art. 6(1)(f) GDPR). The storage period and the transfer to the USA are governed by [GitHub’s privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement); certification under the EU-US Data Privacy Framework will be checked before publication.

## No cookies, no tracking

The website sets no cookies, uses no analytics or advertising services and embeds no fonts, scripts or content from third parties. Every file is loaded from the site’s own origin.

## Local setting

The choice of colour scheme is stored in the browser only after a click (`localStorage`, key `bk-theme`). It contains no personal data and does not leave the device.

## Contact

When an email is sent, the data it contains is processed to answer it (Art. 6(1)(b) and (f) GDPR) and deleted afterwards, unless a statutory retention obligation applies.
