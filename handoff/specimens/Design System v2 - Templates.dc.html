The pages the plan still owed.

The not-found page, the three legal pages in German, and the three content constructs the vocabulary lacked — code, mathematics, diagrams — all rendered at build time with nothing fetched from anyone else’s server. Then a CV, designed here and built with LaTeX from the same tokens. German copy and the legal texts are agent drafts: nothing ships until approved, and none of it is legal advice.

Rule carried throughout
No third-party requestKaTeX and Mermaid stay; their address changes. Math renders at build to HTML and MathML, with the KaTeX stylesheet and fonts served from this origin. Diagrams render at build to inline SVG. A content page ships no script, so a visitor’s IP never reaches a CDN. Gate G-13 on the Audit page fails on any foreign origin.
Astro, not NextThe recipe you pasted is written for Next.js. The equivalents here: remark-math + rehype-katex (output htmlAndMathml), rehype-mermaid with a headless browser in CI, katex/dist/fonts copied to /fonts/katex/, and a Playwright guard that fails on any request off the origin — with one math page and one diagram page in its list, or it proves nothing.

03 · CODE

A dark panel, in both themes.

Owner decision D-035: code sits on a dark panel that is never the page’s own dark, with a six-token palette taken from the dark colour set — so every token clears 4.5:1 on the panel — a copy button and a wrap toggle. Wrap is on by default; the two buttons come from a 1 KB progressive module and the block is complete without it. The highlighter runs at build (shiki mapped to the six classes). A caption makes it a listing with a number from the document code.

Token classes · the whole palette · on #202226 / #26282C
tok-kwKeywords · ultramarine #7C93FF · 5.0:1
tok-fnFunction and type names · amber #F0B400 · 7.5:1
tok-strStrings · jade #00C69F · 6.4:1
tok-numNumbers · sky #54C0F0 · 6.8:1
tok-cmComments · ink-3 #97999D, italic · 4.9:1
tok-opOperators and punctuation · ink-2 #CED0D4. Identifiers stay #F3F5F9.

The bar names the language and the listing; Wrap toggles pre-wrap against a horizontal scroll inside the panel; Copy takes the plain text. Inline code keeps the light wash at 0.9em. Nothing inside a fence is rewritten by any build pass; an unbalanced fence fails the build. The module is the one script a content page with code carries — an exception to the zero-JS rule, recorded with the decision.

04 · MATH

Set at build, numbered from the code.

Display mathematics sits between two hairlines with its number at the right margin; inline mathematics runs in the sentence. Both come out of KaTeX at build as HTML plus MathML, so a reader gets finished markup and a screen reader gets a tree; the page ships no math script and the KaTeX fonts come from this origin. The specimen below is the MathML half, as browsers now render it natively.

For two proportions with baseline p1 and a relative lift λ, the sample per arm at power 1−β is

n= (z1−α/2+z1−β)2·[p1(1−p1)+p2(1−p2)] (p2−p1)2 withp2=p1(1+λ)
(04-01-1)

At p1=0.04, λ=0.10 and 80% power this gives 39,473 visitors per arm — the figure the bench, the fallback text and the listing agree on.

Rules
Authored as $…$ and $$…$$; rendered by rehype-katex with output: "htmlAndMathml", throwOnError: false.
Equation numbers derive from the document code and the order of display blocks; never typed.
Mathematics is ink. The one earned figure in the sentence may be accent text (D-025); symbols never are.
Two $ in ordinary prose (prices) are never paired into math — a regression fixture guards it.
katex.min.css and its woff2 fonts live under /fonts/katex/, subset to the faces used; they count against the font budget.

06 · CV

One A4 page, built with LaTeX from the same tokens.

The CV is the About page in print: name and role, one line of contact, then numbered sections on hairlines — profile, selected work, experience, education, skills. Dates and codes sit in a 32mm mono column; the body hangs on one line to the right. One accent figure per page. ds-update/cv/braga-cv.tex implements it with fontspec and the BKribitz files; employers, roles and dates are fields the build fills from the CV data — none is typed here.

LaTeX · what the file does
engineXeLaTeX or LuaLaTeX; fontspec loads the BKribitz and BKribitz Mono files from ds-update/fonts/ with lining, tabular figures and the slashed zero.
tokensink, ink-2, mid, rule and accent as named colours from colors.css; hairlines 0.4pt; the single accent macro \key{…}.
macros\cvsection{01}{Profile}, \cvrow{dates}{body}, \cvskill{Domains}{…}; the 32mm column and the 4mm gutter are lengths.
dataExperience, education and languages are macros filled from the owner’s CV data; the PDF is the About page’s “Download CV”.
printBlack ink on white; 10.5pt body, 9pt mono labels, 26pt name; no colour but the one accent figure; no icons, no photo unless the About page earns one.
