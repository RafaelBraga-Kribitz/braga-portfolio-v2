# Accessibility statement

This website is meant to conform to the Web Content Accessibility Guidelines 2.2, level AA. The statement is voluntary: the Austrian Accessibility Act (Barrierefreiheitsgesetz) does not cover this private site.

> [!spec] Testing
> - Automated — axe, both colour schemes, 320 to 1,280 px, on every change
> - Manual — Keyboard operation of every tool; zoom to 200%
> - Planned — One pass with a screen reader (NVDA) before publication

## Keyboard

Every page works with the keyboard alone. Tab moves through links and controls in reading order; the first stop is “Skip to content”. Focus is always visible as a 2px ink outline. On the tools, the sliders move with the arrow keys, and each value can also be typed into its field.

> [!spec] Shortcuts
> - 0 — Home
> - 1 to 4 — Work, Writing, Tools, About, as numbered in the header
> - j / k — Next / previous section of the page
> - n / p — Next / previous project or essay
> - u — Up one level
> - l — The same page in German
> - t — Light or dark theme
> - ? — The list of shortcuts; Esc closes it

The shortcuts are single keys and need JavaScript. They do nothing while typing in a field or with Cmd, Ctrl or Alt held, so they never take over a key a browser or a screen reader uses. “Keyboard shortcuts” in the footer opens the same list.

## Limitations

Known limitation: the interactive tools need JavaScript. Without JavaScript, the default scenario is shown as text and a table.
