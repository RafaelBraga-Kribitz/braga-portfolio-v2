# German UI / tools adversarial proofreading

Read-only review, 2026-11-01. Scope: all DE chrome in `src/lib/i18n.ts`, `src/lib/catalogue.ts`, DE home copy, all three tool Astro pages, both tool TSX dictionaries, both model MJS verdict dictionaries, and Shell fallback label. Compared with EN. No edits, tests, or career-fact changes.

## Corrections recommended before language clearance

1. `src/components/Shell.astro`: visible suffix `allein` produces `DEallein`, which is not idiomatic. Replace the no-twin German suffix with ` · nur Deutsch` (and EN `only` with ` · English only` for a legible counterpart). Accessible `translation.unavailable` strings already correctly explain the destination; retain them. If compactness is essential use ` · nur DE`.
2. `src/pages/[lang]/tools/index.astro`: `eine A/B-Stichprobenbank mit Acht-Wochen-Grenze` → `einen A/B-Stichprobenrechner mit Acht-Wochen-Grenze` (adjust whole phrase after `und`). “Stichprobenbank” incorrectly suggests a bank/repository of samples; “Rechner” describes the actual tool.
3. `src/lib/tools/ab-sample-size.mjs`: `pp: 'PP'` → `pp: 'Prozentpunkte'`. The uppercase abbreviation is ambiguous in German; spelling it out avoids confusing an absolute percentage-point difference with a relative percentage lift. No value/formula changes.
4. `src/lib/tools/confusion-matrix.mjs`: `Fehler kosten ${c} über ${n} Fälle: ...` → `Bei ${n} Fällen kosten Fehler ${c}: ...`; `Keine Fehlerkosten über ${n} Fälle: ...` → `Keine Fehlerkosten bei ${n} Fällen: ...`; same `über` → `bei` in `noPositives`. “über … Fälle” is a literal EN calque.
5. `src/lib/i18n.ts`, `keys.docs`: `Nächstes / vorheriges Projekt oder Essay` → `Nächstes / vorheriges Projekt bzw. nächster / vorheriger Essay`. The current adjective gender is wrong for masculine “Essay”.
6. `src/components/tools/AbSampleSizeBench.tsx`: `Stichprobe pro Arm gegen Lift` → `Stichprobengröße pro Arm in Abhängigkeit vom Lift`; `log-Skala` → `logarithmische Skala` in `figNote` and `figAlt`. Suggested full alt: `Besucherzahl pro Arm in Abhängigkeit vom relativen Lift auf einer logarithmischen Skala; markiert sind die Acht-Wochen-Grenze bei diesem Traffic und der aktuelle Lift.` This fixes the literal “against” and awkward passive coordination while preserving meaning.
7. `src/pages/[lang]/tools/confusion-matrix.astro`: `bei einem Preis je Fehlalarm und je Versäumnis` → `bei festgelegten Kosten je Fehlalarm und je übersehenem positiven Fall`. “Versäumnis” is vague in a classifier context; the actual error is a missed positive.
