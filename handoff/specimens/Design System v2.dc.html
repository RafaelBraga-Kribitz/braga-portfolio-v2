01 · GRID

Hairlines live on column lines.

Twelve columns, 32px gutters, 1320px maximum. A rule belongs to the item it sits on, so it spans exactly that item’s columns. Gutters break rules between independent items; an unbroken rule means one shared object.

03 · COLOR

Near-monochrome until a number earns the accent.

Roles, not values. Any element can carry .dark and render inverted on its own. There is no second accent: a theme-shifted block is a dark element, not a colour.
