A display equation, long enough on its own to overrun the reading column at the same width:

$$
\text{Score}(x) = \frac{\sum_{i=1}^{n} w_i \cdot \phi_i(x) - \mu_{\text{baseline}}}{\sigma_{\text{baseline}} + \epsilon} \quad \text{subject to} \quad \sum_{i=1}^{n} w_i = 1
$$

A short fenced code block keeps the language-tag observation repeatable, unrelated to either overflow:

```py
def score(x, weights, baseline_mu, baseline_sigma, eps=1e-6):
    """Standardized weighted score, guarded against a zero-variance baseline."""
    raw = sum(w * phi(x, i) for i, w in enumerate(weights))
    return (raw - baseline_mu) / (baseline_sigma + eps)
```
