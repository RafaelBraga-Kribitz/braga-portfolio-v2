Building a media-mix model from scratch to understand what the libraries hide. The
first question, before any fitting, is narrow: what does one unit of spend in each
channel contribute, net of everything else?

An early, partially-pooled fit gives the contribution shares below. Search carries
more than its 21% spend share suggests — the highlighted bar is the one to
interrogate next.

The estimator is a partially-pooled regression that shares strength across channels.
The core of the fit is short:

```py
import numpy as np

def contribution(spend, beta, adstock):
    """Return per-channel contribution after adstock decay."""
    carried = np.convolve(spend, adstock)[: len(spend)]
    return beta * carried  # net effect, one unit of spend
```
